# AI Metadata Cleaner (MetaClean)

A privacy-first Android application designed to inspect, detect, and sanitize hidden metadata from images, with a specialized focus on **AI generation parameters** and **sensitive GPS/hardware telemetry**.

Built natively with **Kotlin**, **Jetpack Compose (Material 3)**, and **Room Database**.

---

## 🛡️ Core Capabilities & Features

### 1. Deep Metadata Inspection
- **AI Provenance & Generation Parameters**: Scans for embedded AI prompts, negative prompts, model checkpoints, seed numbers, sampler steps, and CFG scale values generated by tools such as **Stable Diffusion**, **Midjourney**, **DALL-E**, and **ComfyUI**.
- **C2PA / Content Credentials**: Detects cryptographic provenance manifests and AI-attribution markers.
- **Precise Location & GPS**: Detects latitude, longitude, altitude, and timestamp offsets that risk physical privacy.
- **Camera & Hardware Identification**: Identifies device manufacturer, model, lens parameters, ISO, aperture, shutter speed, and device serial footprints.
- **Author & Copyright**: Extracts embedded artist credits, software signatures, and license tags.

### 2. Comprehensive Sanitization Modes
- **Full Privacy Shield (Recommended)**: Completely strips 100% of all EXIF headers, XMP segments, IPTC records, and AI chunk tags via pristine in-memory pixel reconstruction.
- **AI-Only Strip**: Eliminates prompt text and model footprints while preserving camera dates and optical configurations if desired.
- **Selective GPS Removal**: Wipes location coordinates while preserving artistic parameters.
- **Customizable Output**: Export to lossless PNG, high-fidelity JPEG, or modern WebP.

### 3. Batch Sanitization
- Multi-select up to 30 images simultaneously using Android's zero-permission **Photo Picker**.
- Real-time progress bar and summary cards with one-tap batch gallery export.

### 4. Local Sanitization History (Room DB)
- Offline database tracking images sanitized, metadata tags eliminated, and bytes saved.
- One-tap re-export or sharing directly to other apps without leaving the application.

### 5. 100% On-Device & Zero-Server Guarantee
- All metadata parsing, EXIF stripping, and pixel re-encoding occur purely in device RAM.
- No network requests, no remote servers, and no tracking telemetry.

---

## 🏗️ Architecture & Technology Stack

- **UI Framework**: Jetpack Compose with Material 3 design system and dark cyber-privacy theme.
- **State Management**: Android Architecture Components MVVM (`ViewModel`, `StateFlow`).
- **Local Persistence**: AndroidX Room Database with Kotlin Symbol Processing (`KSP`).
- **Image Pipeline**: Coil Compose for async rendering, AndroidX `ExifInterface`, and raw chunk byte parsing.
- **Storage & Sharing**: Android MediaStore API (`Pictures/MetaClean`) and AndroidX `FileProvider`.
- **Target SDK**: Android SDK 36 (Android 16 Ready) with minimum SDK 26 (Android 8.0 Oreo).
